# IPEDS Higher Education Data Analysis

This project uses SAS to analyze higher-education institutional data from the Integrated Postsecondary Education Data System (IPEDS).

The project focuses on transforming raw institutional data into organized summary tables and reports while demonstrating data cleaning, statistical analysis, formatting, and validation skills.

## Skills Demonstrated

- SAS programming
- Data cleaning and transformation
- Filtering and conditional logic
- Summary statistics
- Frequency analysis
- Creating derived variables
- Data formatting and labeling
- Sorting and grouping data
- Validating analytical output

## Tools

- SAS
- IPEDS higher-education data

## Project Overview

The analysis uses IPEDS data to create a series of formatted statistical tables describing higher-education institutions. The project includes data preparation, summary statistics, categorical analysis, calculated variables, and customized report formatting.

## Key SAS Techniques

- `DATA` steps
- `PROC MEANS`
- `PROC FREQ`
- `PROC SORT`
- `PROC FORMAT`
- `WHERE` statements
- Variable labels and formats
- Derived variables
